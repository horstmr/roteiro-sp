# Roteiro SP — Comer & Beber

Mapa interativo com indicações de restaurantes e bares em São Paulo (indicações do Augusto Mylla), com o comentário dele em cada lugar. 16 pontos em 5 regiões.

- **`index.html`** — a página do mapa (Leaflet + OpenStreetMap). Abre direto no navegador.
- **`roteiro_sp.kml`** — para importar no [Google My Maps](https://www.google.com/mymaps) e ter um mapa colaborativo.

## Ver localmente
É só abrir o `index.html` no navegador. (No sandbox do Claude o fundo do mapa não aparece; aberto normal, carrega.)

## Publicar no GitHub Pages
Depois do push, vá em **Settings → Pages → Branch: `main` / `(root)` → Save**.
Em ~1 min o mapa fica no ar em `https://SEU_USUARIO.github.io/roteiro-sp/`.

Regiões: Pinheiros/Vila Madalena · Santa Cecília · Centro/República · Liberdade/Paraíso · Barra Funda.
